# 疑わしきは

刑事訴訟法を題材にしたブラウザゲーム（試作版）。`index.html` をブラウザで開けば遊べる。

ひとつの強盗事件を、三つの立場で扱う。

1. **捜査**（捜査官）：勾留期限の中で、取調べ・面割り・捜索・鑑定を選ぶ。近道はいつも手元にある。
2. **起訴**（検察官）：送致記録を読み、どの証拠を法廷に出すか、起訴するかを決める。
3. **公判**（裁判官）：証拠の採否を決め、判決を書く。捜査で知った事実は「あなたの記憶」に残るが、証拠ではない（刑訴法20条6号、256条6項、317条）。

事件の「真相」はゲーム開始時に内部で決まり、最後まで表示されない。

本作はフィクションです。手続は現行法に基づいていますが、ゲームとして簡略化しています。
