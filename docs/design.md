# 調書（仮題） 設計メモ

会話で決まった事項の記録。未決事項は末尾。

## 基本方針
- 刑事訴訟の困難さ、犯人の断定の困難さ、無罪推定の重要性を体験させる。
- 冒頭（初回のみ）：平野龍一『刑事訴訟法概説』（東京大学出版会、1968年）1頁の引用。暗闇に表示。
- 見かけは捜査ものとして始め、テーマを先に明かさない（作者の意図を予想させない）。
- 舞台は現代。事件は強盗（裁判員裁判対象外）→ 取調べの録音録画義務（刑訴法301条の2）がかからない。
- 条文は e-Gov の現行法で照合する（2026年10月時点：218条1項は電磁的記録提供命令を含む文言、黙秘権告知は291条5項）。
- 1回のプレイの長さは試作版程度（+逮捕前段階で10〜15分）。

## モード
- 刑事編：捜査官のみ。検察・裁判はNPC。自分が書いた記録が他人の判断を動かす。
- 判事編：裁判官のみ。NPCの刑事・検事が作った記録を読む。書類の矛盾を指摘する操作が中心。
- 糾問編（両編クリア後）：一人で全部。「あなたの記憶」欄はここでのみ使う。

## 真相
- 開始時に内部で決定（犯人／犯人でない）。表示しない。
- 偶然によってのみ判明：
  - 冤罪：数年後、宮下が別件で逮捕され、金庫の投棄場所を自白 → 再審（令和8年法律第67号による改正後の制度）。
  - 無罪にした被告人が犯人：久住が村井を殺害。判決書「罪となるべき事実」と遺族の意見陳述を突きつける。憲法39条（一事不再理）。
  - どちらも起きないこともある。何も起きないことは何の証明にもならない。
- 二つの結末は同じ重さで作る。
- 種明かし（真相はランダム）は最初の判明の後まで出さない。

## 刑事編
- 序章：事件1「空き巣」（本当に有罪。アリバイの嘘が崩れる。秘密の暴露あり）。チュートリアル兼。
- 本章：青柳書房事件。逮捕前（初動・任意捜査）から。逮捕状請求は警部以上（199条2項）→ 課長に疎明資料を出す。
- 行動の制約は回数ではなく人手（部下3人）と所要日数。逮捕後、課長が人手を別件に回す。
- 主な行動：被害者聴取、地取り、鑑取り、手口照会（宮下）、防犯カメラのリレー捜査、指紋照合（宮下とも7点合致）、通信履歴の保全要請（197条3項）、任意の事情聴取、行動確認、取調べ、捜索（令状／令状なし）、携帯会社・銀行・消費者金融への照会、動画配信事業者への照会（3〜8週間、保全要請がなければ記録なし）、繊維鑑定、面割り（1枚／8枚）、引き当たり、金庫捜索、宮下の捜査。
- 久住の嘘：返済30万円は「母に借りた」→ 実はオンラインカジノの払い出し（賭博罪、刑法185条）。記録は真相によらず同じ。別件逮捕の材料にもなる。
- 別件逮捕：学説が分かれる（別件基準説／本件基準説／実体喪失説、余罪取調べの限界）。ゲームは結論を一つに決めない。刑事編ではNPC裁判官の立場がプレイごとに変わる。判事編ではプレイヤーが選ぶ。
- 真相で変わるもの：自白の出やすさと中身、8枚面割りの結果、金庫の発見確率、動画配信の接続元（犯人：携帯回線／犯人でない：自宅回線）、宮下（犯人でない世界では真犯人）。
- 書類：調書の形式（一問一答／物語式）、報告書に書く項目を選ぶ、要証事実の欄（自白は一つで全部埋まる）。
- 違法・不適切な選択肢には赤い付箋（根拠条文と起こりうること。確率は見せない）。
- 主人公の生活は短い帰宅場面のみ（家計管理はしない）。

## 法の概念の見せ方
- 用語ではなく素朴な問いで判断させ、用語は後で示す（伝聞＝「話した本人に法廷で質問できるか」など）。
- 争いのない証拠は自動採用。

## 引用の配置
- 初回起動：平野『刑事訴訟法概説』。
- 刑事編冒頭：刑訴法1条（「事案の真相を明らかにし」を強調）。
- 判事編で真相判明の後：平野龍一「現行刑事訴訟の診断」（団藤重光博士古稀祝賀論文集第四巻、有斐閣、1985年）422〜423頁の調書と「自室」のくだり → 単独で「わが国の刑事裁判はかなり絶望的である。」
- 全編の最後：刑訴法1条（「個人の基本的人権の保障とを全うしつつ」を強調）。
- 引用は必要最小限、出典明示（著作権法32条）。
- 結末の補足：録音録画義務（301条の2、2019年施行）の対象は起訴事件の約3%。

## 表現・権利
- Papers, Please の仕組み（書類照合）は借りるが、画面構図・キャラクター・音・文言は真似しない。和文の書式、簿冊、判子文化に寄せる。
- 人物グラフィック：48×48 ドット。久住は勾留の進行で4段階に変化。
- 声：全員つぶやき音（人物ごとに高さと音色を変える）。
- 暴力描写の注意書きをタイトルに一行。
