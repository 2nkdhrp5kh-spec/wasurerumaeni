# 判事編「令状当番の夜」 設計メモ

## 骨子
- プレイヤーは北見坂地方裁判所の裁判官。三夜の令状当番（午後9時〜翌朝7時）を務める。
- 請求が一件ずつ机に回ってくる。書類（請求書＋疎明資料）を一枚ずつ開いて読む。読むと時計が進む。
- 判断：逮捕状・捜索差押許可状・身体検査令状は「発付する／却下する」。勾留は「勾留する／却下する（釈放命令）」。延長は「延長する（日数）／却下する」。
  - 捜索差押の一部（車両）だけを削って発付、身体検査令状に条件を付けて発付、もできる。
  - 勾留は、勾留質問（61条・207条1項）をしてからでないと「勾留する」を押せない。却下はいつでもできる。
  - 「資料の追加を求める」＝請求者に電話（30〜60分）。訂正された請求書や差し替えの資料が届くこともあれば、何も出てこないこともある。
- 朝7時に残った請求は「次の当番に引継ぎ」として数える（朝の裁判官が、たいていは発付する）。
- 正誤の点数は出さない。夜と夜のあいだに「その後、耳に入ったこと」の断片だけが聞こえてくる。両方向（却下したら逃げた／何も起きなかった、発付したら何も出なかった、勾留したら自白してあとで撤回した、など）。真相は、偶然によってしか分からない。
- 三夜のあと、短い公判（記録だけを読んで有罪・無罪を決め、理由の中心を一つ選ぶ）。その後、事務処理簿（発付・却下・追加資料・引継ぎの件数と一覧、事務局の中立的な一言）。最後に平野龍一の引用。

## 時間
- 1夜 = 600分（21:00〜7:00）。書類ごとに読む時間（5〜25分。`READ` 倍率で一括調整）。勾留質問30分、電話30〜60分、判断10分。
- 全部読んで全部電話すると、第二夜・第三夜は朝までに終わらない（引継ぎが出る）。全部読むだけなら、ほぼ間に合う。
- 現実との違い：勾留請求・勾留質問は実務では主に昼間に処理される。ゲームでは夜の机にまとめて回ってくる形に簡略化した（「夕方から回ってきた勾留請求の残り」という扱い）。

## 偶然と真相
- 柘植の真相（質店の犯人か否か）は開始時に内部で決める。記録は真相によらず同じ。
- 全編の最後に25%で、偶然による判明（犯人なら知人宅から証拠、犯人でないなら他県で逮捕された男が自供し血痕が一致）。判明したときだけ記録の「真相」欄が「判明」になる。
- 門脇方の捜索で物が出るか（60%）、庄司が出頭するか（85%）も偶然。
- 断片は全部は聞こえてこない（一夜の最初の一件を除き75%）。

## 公判（短編）
- 筒井康平（38）住居侵入・窃盗。屋外側の窓ガラスに指紋1個、9日目の自白（侵入口が客観状況と食い違う、盗品未発見、足跡不一致）、ポスティングのアルバイトという弁解、配布記録は丁目単位。
- 有罪／無罪を選び、理由の中心を一つ選ぶ。有罪の理由に「同種の前科」があるが、前科の内容は横領型で手口も違う（前科による犯人性の推認には厳しい制限があるとされる。最判平成24年9月7日の趣旨）。これを選ぶと控訴趣意書で争われる。どちらを選んでも真相は出ない。

## 実装メモ
- `js/hanji.js` が `G.hanji = { run, DEFS, KIND }` を公開。`run()` は終わると `G.meta.runs` に一行を足して `G.saveMeta()` する。
- 人物（G.CHAR / G.portraits.PEOPLE に追加）：`hj_clerk`（水野書記官）、`hj_keibu`（黒田警部）、`hj_kenji`（三輪検事）、顔なし：`hj_tochoku`（署の当直）、`hj_susp`（勾留質問の被疑者。名前は質問のたびに差し替え）。
- 背景：`BG_CHAMBERS = 'chambers'`（未定義なら dark で描かれる）。勾留質問は `court` を暗くして、電話は `phone`、公判は `court`。
- 条文帳：判事編の画面では「条文帳」ボタンを判事編用（上の条文＋既存の G.LAW）に差し替える。G.LAW 自体には何も足していない（刑事編の条文帳は変わらない）。
- 請求の追加は DEFS に一件足すだけでよい（night, at, kind, from, sus, charge, docs, iv, call, after, when）。
