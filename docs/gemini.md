# Gemini に頼む作業

Claude（コードを書く側）と別のAIに読ませて、Claude が見落とす「意味・本当らしさ・ヒントの出しすぎ」を拾う。
**Gemini にはコードを直させない。報告だけ。** 直すのは Claude（同じコードを二つのAIが触ると食い違うため）。
報告が来たら、そのまま Claude に貼り付ける。

---

## A. Jules（初見の読み手・実務家）— 節目ごとに一回

1. https://jules.google.com を開き、GitHub の `2nkdhrp5kh-spec/wasurerumaeni` をつなぐ。
2. ブランチは **`chousho-game`** を選ぶ。
3. 次の文をそのまま貼り付けて頼む。

```
このリポジトリは、日本の刑事手続を題材にしたブラウザのゲーム「調書」（仮題）です。
あなたの仕事は【読んで報告すること】だけです。コードは一切変更しないでください。ブランチもプルリクエストも作らないでください。

準備：
- node tools/dump-text.js を実行すると、ゲームの文が tools/out/all-text.md に書き出されます。まずこれを読んでください。
- 作り方の決まりは docs/rules.md、設定の台帳は docs/ledger.json、事実の根拠は docs/facts.md にあります。
- 必要なら js/ 以下のコードも読んでください（case-*.js が事件、world5.js と case-go.js が第五章）。

次の三つの立場で、それぞれ問題点を挙げてください。

1. 初めて遊ぶ人として
   - 何の事件で、何をすればよいかが分からない所
   - 用語の説明がなく意味が取れない所
   - 答えやヒントを、ゲームが先に言ってしまっている所（記録や選択肢に結論が書いてある等）
   - 台詞の時刻で、午前か午後か分からない所
2. 日本の警察・検察・裁判の実務家として
   - 手続の順番・必要な令状・期間・書類の書式が、実務と違う所
   - 数字（金額・日数・保存期間・年齢・収入）が現実離れしている所
   - 人物の言動が、その職業の人として不自然な所
3. 物語の編集者として
   - 人物の名前・年齢・関係・日付が、場面や事件の間で食い違っている所
   - 前に言ったことと後で言うことが矛盾している所
   - docs/rules.md の決まりに反している所

報告の形（日本語で、この形の表にしてください）：
| 重さ（高・中・低） | ファイルと行（分かれば） | 問題の文（そのまま引用） | 何が問題か | 直し方の案 |

重さ「高」は、遊べない・法的に誤り・物語が破綻する、のどれか。推測で言う所は「推測」と書いてください。
見つからなかった観点は「見つからなかった」と書いてください。
```

## B. Gemini アプリの Deep Research（判例・実務の事実の確認）

1. Gemini アプリで「Deep Research」を選ぶ。
2. 次の文を貼り付けて頼む（表は docs/facts.md からそのまま写してよい）。

```
日本の刑事手続を題材にしたゲームの監修のために、次の事実が正しいかを一次の出典で確かめてください。
出典は、できるだけ裁判所の裁判例検索（courts.go.jp）、e-Gov法令検索、警察庁・法務省・総務省などの公的な資料にしてください。

【判例】それぞれについて、(1) 実在するか、(2) 裁判所と年月日は正しいか、(3) 事件番号、(4) 下の「要旨」の内容が判決・決定の内容と合っているか、を確かめてください。
- 最判昭和53年9月7日：違法収集証拠。令状主義の精神を没却する重大な違法があり、将来の違法捜査抑制の見地から相当でないときは証拠能力を否定
- 最判昭和41年7月1日：約束による自白。検察官の「自白すれば起訴猶予」を信じた自白は任意性に疑い
- 最決昭和59年2月29日：任意取調べの限界。社会通念上相当と認められる方法・態様・限度で許容（高輪グリーンマンション事件）
- 最大判昭和45年11月25日：偽計による自白。偽計で心理的強制を受け虚偽自白が誘発されるおそれがあれば任意性に疑い
- 最大判平成11年3月24日：接見指定。捜査に顕著な支障が生ずる場合に限る。現に取調べ中・確実な予定がある場合など
- 最判平成12年6月13日：初回接見。逮捕直後の初回接見は特に重要。即時または近接した時点での短時間の接見を認めるべき
- 最判平成21年4月14日：痴漢事件。被害者の供述の信用性は特に慎重に判断する必要がある
- 最大決昭和33年7月29日：差し押さえるべき物の明示。例示のあとの「その他本件に関係ありと思料せられる一切の文書及び物件」は明示に欠けない

【実務・生活の事実】それぞれ、正しいか・おおよその実際の値はどれくらいか、を出典つきで。
- コンビニの防犯カメラの保存期間（ゲームでは14日）
- 銀行ATMの防犯カメラの保存期間（ゲームでは60日）
- 通話履歴・基地局の記録は、捜査関係事項照会では通信会社は出さず、差押許可状が要るか
- 通信会社が通話の記録を保存する期間（ゲームでは90日）
- プリペイド携帯電話の購入時に本人確認が要るか（携帯電話不正利用防止法）
- 基地局一つがカバーする範囲（街なか）
- 変死体の司法解剖は発見から何日くらいで行われるか。死亡推定時刻の幅はどれくらいで出るか
- 塾講師のアルバイトをする大学院生の月収のおおよそ
- キャッシュカードでのATMの1日の引き出し上限（多くの銀行で）
- 取調べの録音・録画が義務になる事件の範囲（2019年施行の改正刑訴法）

報告の形：
| 項目 | 正しい／誤り／一部違う | 正しい内容 | 出典（URL） |
```

## C. 報告を受けたあと（Claude がやること）

- 判例：正しければ docs/facts.md の状態を ✅ にし、出典を書く。違えばゲームの文を直す。
- 事実：docs/facts.md を更新し、ゲームの数字を合わせる。
- Jules の指摘：重さ「高」から順に直し、`node tools/check-all.js` を通してから見せる。機械で見つけられる種類の指摘なら、検査の道具にも足す（同じ間違いを二度させない）。
