# 事実の台帳（本当らしさの根拠）

ゲームに書く「現実の事実」と、その根拠。確かめたら状態を ✅ にして、出典を書く。
tools/check-law.js は、ゲームに出てくる判例のうち、ここで ✅ になっていないものを知らせる。
確かめ方は docs/gemini.md（Gemini の Deep Research への頼み方）を参照。
